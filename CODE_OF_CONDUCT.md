# Code of Conduct

Sangop is a small project with one maintainer. We want every issue, discussion and
review to be useful and respectful.

## Expected

- Be kind and patient. Assume good intent; criticise code and ideas, not people.
- Keep to the topic of the project.
- Use synthetic examples only. Never post real personal data, real credentials or
  production logs - yours or anyone else's.

## Not accepted

- Harassment, insults, threats, or discriminatory remarks of any kind.
- Sharing someone's private information without their permission.
- Spam, vote manipulation, or repeated off-topic promotion.

## Reporting

Write to arvind@sangop.com. Reports are read by the maintainer and kept as private as
possible. Security vulnerabilities go through SECURITY.md, not here.

## What the maintainer may do

Edit, hide or delete comments, lock threads, and block accounts from the project's
spaces, temporarily or permanently. The maintainer may also step back from a
discussion that becomes abusive.

This code applies in the project's GitHub repository, issues, discussions and pull
requests, and when someone represents the project elsewhere.
