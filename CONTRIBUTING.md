# Contributing to Sangop

Thank you for your interest in Sangop.

Everyone who takes part follows our [Code of Conduct](CODE_OF_CONDUCT.md).

## Current policy

Issues and Discussions are welcome. External pull requests are not accepted yet.

- **Bug reports and ideas are welcome** via GitHub Issues and Discussions. Never include real
  personal data, credentials or production logs - use synthetic examples only.
- **Security issues:** report privately, see [SECURITY.md](SECURITY.md).
- **Code contributions:** we are not yet accepting external pull requests.
  Before we do, contributors will be asked to sign a Contributor License
  Agreement (CLA) so that the project's licensing stays clear for all users.
  This page will be updated when the CLA is available.

## Developer Certificate of Origin (DCO)

Every commit in this project, the maintainer's own commits included, must carry a
sign-off line:

    Signed-off-by: Your Name <you@example.com>

Add it automatically with `git commit -s`. By signing off you certify the
[Developer Certificate of Origin 1.1](https://developercertificate.org/): that you wrote the
change or otherwise have the right to submit it under the project's licence (Apache-2.0).

The DCO documents where each change came from; it does **not** transfer ownership. When
external pull requests open, the CLA mentioned above will still be required **in addition**
to the DCO sign-off. Until then external pull requests remain closed and will not be merged.

## Ground rules for any future contribution

- Only code you wrote yourself, or code under MIT / Apache-2.0 / BSD licences
  with the licence notice preserved.
- Tests and examples must use synthetic data only.
- No network calls or telemetry may be added to the library.
